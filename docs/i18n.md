# Multilingua (i18n)

Il testo sorgente e' sempre l'**italiano**. La chiave del catalogo e' la stringa italiana stessa.

## Come funziona
- `src/i18n/core.ts`: `t('Hai {0} impegni', n)` (testo con segnaposto) e `translateText(testo gia' composto)` (corrispondenza esatta, poi per modello con `{0}`).
- `src/i18n/languages.ts`: le 12 lingue (it, en, es, fr, de, pt, zh, hi, ar, ru, ja, id).
- `src/i18n/apply.ts`: attiva la lingua e l'RTL (arabo). `src/i18n/catalogs.ts` registra i cataloghi.
- `src/i18n/locales/<lang>.json`: `{ "testo italiano": "traduzione" }`. Le parti variabili usano `{0}`, `{1}`... nello stesso ordine in tutte le lingue (l'insieme dei segnaposto deve coincidere).
- `src/components/T.tsx`: `Text` e `TextInput` che traducono da soli (importarli da `@/components/T`).
- Fuori dai componenti (toast, Alert, testi composti in logica) usare `t(...)` dentro funzioni/componenti, mai a livello di modulo.

## Elenco delle stringhe: `src/i18n/source.json`
Generato da `node scripts/extract-i18n.mjs` (AST con `@babel/parser`, nessuna dipendenza nuova). Scrive anche `src/i18n/source.meta.json` (`count`, `byFile`, `withPlaceholders`).

Criteri di estrazione (in `src/**/*.ts(x)`, esclusi `src/i18n/locales`, `tests`, `node_modules`, `src/data/translations.json` e i dati demo `seed.ts`, `marketSeed.ts`, `jobsSeed.ts`, `moodDemo.ts`, `network-seed.json`, `src/store/demo.ts`):
- testo JSX (`JSXText`) con lettere, spazi collassati;
- attributi JSX di testo: `title label placeholder accessibilityLabel accessibilityHint text subtitle hint description header empty caption sub desc detail tagline cta name message body heading emptyText confirmLabel cancelLabel` (letterali, template, condizionali);
- espressioni `{...}` figlie di elementi JSX con stringhe / template / condizionali / `&&`;
- primo argomento di `toast()`, `showUndoToast()`, `t()`; titolo, messaggio e bottoni di `Alert.alert()`; `message`/`title` di `Share.share()`;
- proprieta' di oggetti con chiavi di testo (`title text label name desc description detail hint tagline placeholder msg message body sub subtitle cta why summary sentence tip action explanation reason heading note question answer ...`);
- in piu', qualsiasi altro letterale "italiano-like" che non sia chiaramente logica (confronti `===`, `case`, import, tipi, chiavi di oggetto, argomenti di `includes/startsWith/split/test/...`, `console.*`, `go()`).
- "italiano-like": contiene lettere e (spazio, oppure accentate italiane, oppure iniziale maiuscola con >= 3 caratteri); scartati identificatori, camelCase, percorsi, URL, colori, `lp2-`, codice (`=>`, `;`, `{`), SOLO_MAIUSCOLE, nomi di file.
- Template con espressioni: `${x}` diventa `{0}`, `{1}`... in ordine; i rami di condizionali dentro il template (`${n === 1 ? 'impegno' : 'impegni'}`) sono estratti anche come voci separate.
- Normalizzazione: trim, spazi collassati, deduplica, ordine alfabetico. `EXTRA` e `NOISE` in cima allo script correggono a mano casi noti.

## Aggiungere una stringa
1. Scrivere il testo italiano nel componente (dentro `<Text>/Btn/Pill/Body` si traduce da solo) oppure usare `t('Testo {0}', valore)` fuori dai componenti.
2. `node scripts/extract-i18n.mjs` per rigenerare `source.json`.
3. Aggiungere la traduzione in tutti i `src/i18n/locales/<lang>.json` (stessa chiave, stessi segnaposto).
4. `node scripts/check-i18n.mjs` per verificare.

## Aggiungere una lingua
1. Aggiungere il codice in `src/i18n/languages.ts` (nome nativo, direzione RTL se serve).
2. Creare `src/i18n/locales/<lang>.json` (anche `{}`) e registrarlo in `src/i18n/catalogs.ts`.
3. Aggiungere il codice alla lista `LANGS` in `scripts/check-i18n.mjs` e `tests/i18nCatalog.test.mjs`.

## Controllare i cataloghi
- `node scripts/check-i18n.mjs [--min=NN] [--lang=en,es]` stampa per lingua copertura, chiavi mancanti (prime 20), chiavi non presenti nel sorgente, valori vuoti, segnaposto diversi e (per zh hi ar ru ja) valori identici al sorgente. Exit 1 se ci sono segnaposto diversi o valori vuoti; la copertura bassa e' solo un avviso, a meno di `--min=NN`.
- `node --experimental-strip-types --test tests/i18nCatalog.test.mjs`: nessun valore vuoto, segnaposto coerenti, chiavi presenti nel sorgente (la copertura non e' verificata; passa anche con `{}`).
